⚙️ How the AI Recommendation Engine Works

This prototype uses a transparent, explainable rule-based decision engine structured around four core functionalities:

1️⃣ A. Information Retrieval

Normalizes query tokens, expands synonyms (e.g., "AI" → Artificial Intelligence, "AWS" → Cloud Computing), and matches against subjects, titles, and curriculum keywords with up to 50 base relevance points.

2️⃣ B. Filtering

Screens retrieved candidates against the selected difficulty tier (Beginner, Intermediate, Advanced) and learning purpose. Detects level distance gaps and applies fallback logic when no exact matches exist.

3️⃣ C. Multi-Attribute Comparison

Scores each candidate using a 100-point formula: Total = Subject (50) + Difficulty (25) + Purpose (25). Classifies books into Optimal Fit (≥88%), Strong Fit (72-87%), Moderate Fit (50-71%), and Partial Match (<50%).

4️⃣ D. Recommendation & Reasoning

Presents the top 3 books with natural-language explanations explaining precisely why each textbook fits the student's background, difficulty level, and study objective.
